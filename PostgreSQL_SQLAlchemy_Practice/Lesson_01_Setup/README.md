# Lesson 01 - Setup

## Objective

The goal of this lesson is to prepare the development environment for working with PostgreSQL and SQLAlchemy.

In this lesson, we install the required Python packages and verify that PostgreSQL is running correctly before writing any SQLAlchemy code.

---

## Topics Covered

- Python
- pip
- PostgreSQL Server
- SQLAlchemy
- psycopg2-binary
- PostgreSQL Connection Test

---

## Requirements

- Python 3.x
- PostgreSQL
- SQLAlchemy
- psycopg2-binary

---

## Outcome

After completing this lesson, the development environment is ready for SQLAlchemy practice.
