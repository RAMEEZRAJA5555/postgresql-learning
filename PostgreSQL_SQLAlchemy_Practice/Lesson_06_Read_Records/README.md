# Lesson 06 - Read Records

## Objective

In this lesson, we learn how to retrieve records from a PostgreSQL database using SQLAlchemy ORM.

Instead of writing SQL SELECT queries, SQLAlchemy provides methods to fetch data as Python objects.

---

## Topics Covered

- Session
- session.query()
- all()
- first()
- filter_by()

---

## What You Learned

- Read all records
- Read the first record
- Read specific records using filters

---

## Files

- read_records.py → Read records using SQLAlchemy ORM.

---

## Outcome

After completing this lesson, you can retrieve data from PostgreSQL using SQLAlchemy ORM without writing SQL.
