# Lesson 08 - Delete Records

## Objective

In this lesson, we learn how to delete records from a PostgreSQL database using SQLAlchemy ORM.

Instead of writing SQL DELETE statements manually, SQLAlchemy allows us to retrieve an object and remove it using the Session.

---

## Topics Covered

- session.query()
- filter_by()
- first()
- session.delete()
- session.commit()

---

## What You Learned

- Find a record
- Delete a record
- Save changes
