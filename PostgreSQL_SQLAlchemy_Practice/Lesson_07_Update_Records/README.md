# Lesson 07 - Update Records

## Objective

In this lesson, we learn how to update existing records in a PostgreSQL database using SQLAlchemy ORM.

Instead of writing SQL UPDATE queries manually, we retrieve an object, modify its attributes, and save the changes using a Session.

---

## Topics Covered

- session.query()
- filter_by()
- first()
- Updating Objects
- session.commit()

---

## What You Learned

- Find a record
- Modify object attributes
- Save changes to PostgreSQL

---

## Files

- update_record.py → Updates an existing record.

---

## Outcome

After completing this lesson, you can update records using SQLAlchemy ORM without writing SQL.
