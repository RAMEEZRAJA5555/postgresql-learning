# Lesson 02 - Database Connection

## Objective

The purpose of this lesson is to understand how Python connects to a PostgreSQL database using SQLAlchemy.

Before performing CRUD operations, SQLAlchemy needs a connection to the PostgreSQL server. This connection is created using a Database URL and SQLAlchemy's Engine.

---

## Topics Covered

- Database URL
- SQLAlchemy Engine
- create_engine()
- Connecting Python to PostgreSQL
- Executing the first SQL query

---

## What You Learned

- Why a database connection is required
- How SQLAlchemy communicates with PostgreSQL
- The role of Engine
- How the Database URL is structured
- How to execute a simple SQL query

---

## Files

- database.py → Database connection example
- connection_flow.md → Database connection workflow

---

## Outcome

After completing this lesson, you can successfully connect a Python application to a PostgreSQL database using SQLAlchemy.
